PROJECT / 01

Staff Evaluation System

I built a web tool for staff reviews. Evaluators can select a staff member, score criteria, add comments, and save a review. It includes sign-in, manager controls, and database-backed records.

ProblemStaff reviews need a consistent flow for scoring, comments, saved records, and manager review.

My workI built the interface, evaluation flow, Supabase data connection, and automated site, autosave, and realtime load tests.

ResultA working database-backed evaluation tool with authenticated access, repeatable review steps, and test scripts that can be inspected in the public repository.
